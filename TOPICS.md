```bash

  --add-topic robotics \
  --add-topic ros2 \
  --add-topic gazebo \
  --add-topic claude \
```

## Make public (when ready)

```bash
gh repo edit Lazaro549/prompt-to-robot-actions --visibility public
```

Or: GitHub UI → Settings → Danger Zone → Change visibility → Public.

> Note: the GitHub MCP tools available in this environment cannot change
> visibility or topics; run the commands above from your machine.
